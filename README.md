# ZYNTRAVA Rewards

A premium global rewards platform foundation with Firebase Authentication, Firebase Realtime Database and a Vercel server-side reward API.

## Live platform modules
- Authentication and unique member identity
- Country-aware payout methods
- Verified task engine
- Proof submission and admin review
- Server-issued points
- Wallet and transaction ledger
- Withdrawal request, approval, rejection and paid workflow
- Daily reward API
- Promotional spin API
- Referral relationship tracking
- Live notifications
- Live leaderboard using public-safe profile data
- Admin control center
- Approved rewarded-campaign area

See `PRODUCTION-SETUP.md` before deployment.
