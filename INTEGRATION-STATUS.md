# Zyntrava Core Complete

This bundle consolidates the latest core fixes without changing the existing Firebase configuration.

## Included
- Consolidated single Vercel API router
- CPX Research API survey listing + secure postback
- CPX Firebase-session timing fix
- Dynamic opportunities/tasks
- Secure task approval and reward ledger
- Referral, daily reward and spin server-side protection
- ZN wallet/withdrawal backend
- Profile and completion reward flow
- Notifications and transaction ledger
- Node.js 24.x engine for Vercel

## Vercel environment variables
Keep the existing server variables and CPX_SECURE_HASH. Do not put private Firebase Admin credentials in frontend files.
